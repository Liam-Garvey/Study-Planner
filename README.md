Once the project is run, you can select study sessions, a subject, or all assignments. 
Selecting all assignments displays all current assignments
Selecting a subject displays all information associated with that subject, including its assignments. While there, you can select assignments to update them and their associated milestones, or add new assignments using the add assignment button.
Selecting the study sessions from the main page allows you to view past and upcoming study sessions, as well as add and delete study sessions
